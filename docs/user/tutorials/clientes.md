# Gestión de Clientes

## Objetivo
Aprender a registrar, buscar y administrar clientes.

---

## Requisitos
- Permiso: `cliente leer`, `cliente crear`, `cliente editar`

---

## 1. Lista de Clientes

1. Andá a **Gestión Comercial → Clientes → Lista de Clientes**.
2. Se muestra una tabla con todos los clientes registrados.
3. Usá el buscador para filtrar por razón social o RUC.
4. Usá los botones de exportación para descargar la lista.

![Lista de clientes][screenshot-clientes-index]

---

## 2. Registrar un Cliente Nuevo

1. Andá a **Gestión Comercial → Clientes → Registrar Cliente**.
2. Completá los campos:

| Campo | Obligatorio |
|-------|:-----------:|
| **Razón Social** | ✅ |
| **RUC** | ✅ (único por cliente) |
| **Dirección** | |
| **Correo** | |
| **Teléfono** | |
| **Celular** | |
| **Observación** | |

3. Hacé clic en **Guardar**.

![Formulario de cliente][screenshot-clientes-create]

> 📝 Podés usar la búsqueda rápida de clientes desde cualquier formulario de venta.

---

## 3. Editar un Cliente

1. En la lista, hacé clic en el botón **Editar** (✏️).
2. Modificá los datos necesarios.
3. Hacé clic en **Guardar**.

## 4. Cambiar Estado

Podés activar o desactivar un cliente desde la lista. Los clientes inactivos no aparecerán en las búsquedas de ventas.
