# Gestión de Proveedores

## Objetivo
Aprender a registrar y administrar proveedores.

---

## Requisitos
- Permiso: `proveedor leer`, `proveedor crear`, `proveedor editar`

---

## 1. Lista de Proveedores

1. Andá a **Gestión Comercial → Proveedores → Lista de Proveedores**.
2. Se muestra una tabla con todos los proveedores registrados.
3. Usá el buscador para filtrar.

![Lista de proveedores][screenshot-proveedores-index]

---

## 2. Registrar un Proveedor Nuevo

1. Andá a **Gestión Comercial → Proveedores → Registrar Proveedor**.
2. Completá los campos:

| Campo | Obligatorio |
|-------|:-----------:|
| **Razón Social** | ✅ |
| **RUC** | |
| **Dirección** | |
| **Correo** | |
| **Teléfono** | |
| **Celular** | |
| **Observación** | |

3. Hacé clic en **Guardar**.

---

## 3. Editar un Proveedor

1. En la lista, hacé clic en **Editar** (✏️).
2. Modificá los datos y guardá.

## 4. Eliminar un Proveedor

1. En la lista, hacé clic en **Eliminar** (🗑️).
2. Confirmá la operación.

> ⚠️ No se puede eliminar un proveedor que tenga compras registradas.
