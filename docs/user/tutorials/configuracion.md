# Configuración del Sistema

## Objetivo
Aprender a modificar la configuración general del sistema.

---

## Requisitos
- Permiso: `configuracion modificar`

---

## 1. Acceso a la Configuración

1. Andá a **Administración → Configuración**.
2. Se muestra una lista de opciones de configuración del sistema.

![Configuración][screenshot-configuracion]

---

## 2. Opciones de Configuración

| Opción | Descripción | Valores |
|--------|-------------|---------|
| **Condición de Venta** | Permite elegir entre Contado/Crédito al hacer una venta | Activado/Desactivado |
| **Ventas** | Habilita o deshabilita el módulo de ventas | Activado/Desactivado |

### Cómo cambiar una opción

1. Buscá la opción en la lista.
2. Cambiá el estado usando el interruptor (toggle).
3. El cambio se aplica inmediatamente.

> ⚠️ Las configuraciones afectan a todo el sistema. Modificalas con cuidado.

---

## 3. Consejos

- 📝 Si desactivás **Condición de Venta**, todas las ventas serán obligatoriamente al contado.
- 📝 Si desactivás **Ventas**, el módulo completo de ventas dejará de estar operativo.
