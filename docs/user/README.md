# EasyStock — Manual de Usuario

**EasyStock** es un sistema de gestión de stock, ventas, compras y caja. Este manual está dirigido a los usuarios del sistema: administradores, encargados de depósito, cajeros y personal operativo.

- `📝` Nota o consejo
- Los textos en `código` son nombres de botones, campos o rutas
- Los pasos numerados deben seguirse en orden
